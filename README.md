# tihonove.dev-apps

Реестр проектов в Kubernetes-кластере `tihonove.dev`.

Один файл в [`apps/`](apps/) = один проект. Кластер (Flux) следит за этим репо: файл смёрджен — проект
развёрнут, файл удалён — проект удалён.

Как подключить проект — **[GUIDE.md](GUIDE.md)**.

| Путь | Что |
|---|---|
| `apps/<app>.yaml` | регистрации проектов |
| `templates/app.yaml` | шаблон регистрации |
| `templates/project/` | заготовки для репо проекта: `deploy/` и `.sops.yaml` |
| `keys/cluster-age.pub` | публичный age-ключ кластера, им шифруются секреты проектов |
| `keys/owner.asc` | публичный GPG-ключ владельца платформы |
